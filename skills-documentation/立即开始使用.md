# 立即开始使用

## 🚀 3 步快速开始

### 步骤 1：打开浏览器
访问 http://localhost:7788/

### 步骤 2：入场安检
1. 点击"入场安检"
2. 输入身份证号：`110101199003151234`
3. 点击"验证身份"
4. 拖拽或选择 `test_image.jpg`
5. 点击"识别物品"
6. 查看识别结果

### 步骤 3：离场安检
1. 点击"离场安检"
2. 输入相同的身份证号
3. 点击"验证身份"
4. 上传图片
5. 点击"识别物品"
6. 查看比对结果
