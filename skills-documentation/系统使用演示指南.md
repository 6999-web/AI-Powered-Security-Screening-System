# 系统使用演示指南

## 🎬 完整演示流程

### 第一步：打开系统

1. 打开浏览器
2. 访问 http://localhost:7788/
3. 看到系统主界面

### 第二步：入场安检演示

#### 2.1 验证身份
1. 点击"入场安检"标签
2. 在身份证号输入框输入：`110101199003151234`
3. 点击"验证身份"按钮
4. 看到提示"✅ 身份验证成功"

#### 2.2 上传图片
1. 在"选择图片"区域拖拽 `test_image.jpg`
2. 或点击区域选择文件
3. 看到图片预览

#### 2.3 识别物品
1. 点击"识别物品"按钮
2. 等待识别完成（通常 2-5 秒）
3. 看到识别结果：
   ```
   ✅ 笔记本电脑或平板电脑 x1
   ✅ 方形电子设备或充电宝 x1
   ✅ 钥匙或金属挂件 x1
   ✅ 文件夹或硬质文档袋 x1
   ✅ 梯形塑料盒或收纳盒 x1
   ```

#### 2.4 查看详细信息
- 物品总数：5
- 总重量：2.17 kg
- 每个物品的类别和置信度

### 第三步：离场安检演示

#### 3.1 验证身份
1. 点击"离场安检"标签
2. 输入相同的身份证号：`110101199003151234`
3. 点击"验证身份"按钮
4. 系统自动加载入场记录

#### 3.2 上传图片
1. 上传同一张图片（或不同的图片）
2. 点击"识别物品"

#### 3.3 查看比对结果
- **比对状态**：正常 / 异常
- **异常物品**：如果有差异会显示
- **建议**：系统给出的处理建议

### 第四步：查看数据看板

1. 点击"数据看板"标签
2. 看到统计信息：
   - 总入场数
   - 总离场数
   - 总异常数
   - 当前在场人数

3. 看到最近的记录列表

### 第五步：查看异常记录

1. 点击"异常记录"标签
2. 看到所有异常记录
3. 每条记录显示：
   - 用户 ID
   - 异常类型
   - 异常描述
   - 入场时间
   - 离场时间

## 🔍 故障排查

### 问题 1：识别失败
**症状**：点击"识别物品"后没有反应

**解决**：
1. 检查图片是否上传成功
2. 检查图片尺寸是否 >= 10x10 像素
3. 查看浏览器控制台是否有错误
4. 查看后端日志

### 问题 2：身份验证失败
**症状**：点击"验证身份"后提示错误

**解决**：
1. 检查身份证号是否为空
2. 检查身份证号格式是否正确
3. 检查后端服务是否运行

### 问题 3：页面加载失败
**症状**：访问 http://localhost:7788/ 显示空白

**解决**：
1. 检查前端服务是否运行
2. 检查端口 7788 是否被占用
3. 清除浏览器缓存
4. 尝试使用无痕模式

### 问题 4：API 连接失败
**症状**：识别时提示"网络错误"

**解决**：
1. 检查后端服务是否运行
2. 检查端口 9527 是否被占用
3. 检查防火墙设置
4. 查看浏览器控制台错误
